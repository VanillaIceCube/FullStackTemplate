## 2026-09-12 - Machine-Managed Security Alert Issues **Learning:** Security alert group issues (e.g., #114, #82, #81, #80) are generated and synchronized by the `.github/actions/security-alerts` workflow and contain embedded HTML identification markers. **Action:** Treat security alert group issues as machine-managed and avoid manual title/body restructuring or manual status churn on them.

## 2026-09-12 - Active Specialist PR Scope Protection **Learning:** Active PRs submitted by specialist agents (Marty 🦀, Nora 🐚, Kris 🦐, Forge 🔧) represent work actively in flight. Reorganizing underlying issue scopes or acceptance criteria underneath an active PR creates scope drift for the implementing agent. **Action:** Protect active work by deferring issue scope modifications or closures until the active implementation PR is merged or closed.
