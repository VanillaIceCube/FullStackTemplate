# Otto's Journal — Backlog & Project Organization Learnings

## 2026-09-17 - Offline Sandboxed Backlog Reconciliation **Learning:** In sandboxed execution environments where remote GitHub API integration (`gh` CLI or issue endpoints) is restricted or unavailable, backlog audit and reconciliation rely on inspecting local branch patterns (`origin/jules/*`, `origin/codex/*`, `origin/dependabot/*`), commit history, and automated workflow scripts (`.github/actions/security-alerts`, `scripts/create-github-project.ps1`). **Action:** Reconcile active implementation states and issue dependencies against active git branches and merged pull request logs before modifying backlog scope or status.

## 2026-09-17 - Protecting Active Specialist Work in Flight **Learning:** Active implementation branches created by specialist agents (e.g., Marty 🦀, Nora 🐚, Kris 🦐) represent work actively in flight. Modifying acceptance criteria, reassigning, or splitting issues underneath active implementation PRs causes scope drift and disrupts ongoing development. **Action:** Preserve active issue scopes and defer major organizational restructuring until the corresponding implementation PR merges or closes.
