## 2026-09-07 - Testing MUI Disabled Form Submission Buttons **Learning:** Material UI `<Button disabled>` components apply `pointer-events: none`, causing `@testing-library/user-event` `click()` calls on disabled submit buttons to throw pointer interaction errors. **Action:** Use `fireEvent.submit` on the submit button or form element to test submission guards without violating Testing Library's no-node-access rule or failing pointer event checks.
