## 2026-09-09 - Fallback Authorization Headers in Frontend API Clients **Learning:** API clients like `notificationApiClient.js` previously constructed `Authorization: Bearer undefined` headers when called without explicit token arguments, resulting in unnecessary HTTP 401 request failures or backend decoding errors. **Action:** Always use token fallback resolution (`sessionStorage.getItem('accessToken')`) wrapped in `try/catch` and omit the `Authorization` header completely when no valid token string is available.
