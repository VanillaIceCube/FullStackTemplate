## 2026-09-16 - Frontend Service Boundaries and HTTP Utility Decoupling **Learning:** Auth session management (`persistAuthSession`, `clearAuthSession`) belonged together in `authSession.js`, whereas generic HTTP response parsing (`safeReadJson`, `getResponseErrorMessage`, `readOkJson`) was previously embedded inside `authSession.js`. Decoupling HTTP utilities into `httpUtils.js` creates clear responsibility boundaries while preserving backward compatibility via re-exports. **Action:** Maintain distinct boundaries between browser storage/session state managers and transport/response parsing utilities in `frontend/src/services/`.
