## 2026-09-01 - Decoupling Layout Shells from Domain Feature States **Learning:** Combining domain-specific component state, asynchronous polling/fetching, and deep popover UI logic inside top-level layout shells (like `AppHeader`) obscures ownership and prevents standalone component testing. **Action:** Extract domain popovers and feature-specific widgets (such as `NotificationsPopover`) into focused modular components so top-level page shells remain lightweight layout orchestrators.
